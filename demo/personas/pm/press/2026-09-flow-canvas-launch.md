# Macrohard launches Flow Canvas, a visual editor for workflows

*Press release · 16 September 2026 · For immediate release*

LONDON. Macrohard today launched Flow Canvas, a drag-and-drop editor that lets operations teams
build and change workflows without writing code. Flow Canvas, developed under the codename
Project Kite, is available today on every Macrohard Flow plan at no extra cost.

"Our customers told us that changing a workflow shouldn't need a ticket to IT," said Priya Shah,
product manager for Macrohard Flow. "With Canvas, the person who runs the process can change it
in minutes."

Flow Canvas includes:

- A visual editor with more than 40 ready-made steps
- Version history, so any change can be rolled back
- Live previews that show where each item would go before a workflow is published

Flow Canvas is available now at macrohard.example/flow/canvas.
