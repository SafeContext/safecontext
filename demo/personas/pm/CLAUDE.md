# Macrohard Flow: product docs

I'm Priya Shah, product manager for Macrohard Flow (our workflow app for operations teams).
This folder holds my working docs.

- `roadmap/`: the plan for the next four quarters. Internal.
- `launches/`: launch plans, one per feature.
- `press/`: press releases and blog posts that have gone out. Public.
- `metrics/`: weekly product updates for the leadership team.
- `research/`: notes from customer interviews.

Write in plain British English. Keep updates short: lead with what changed.
